# Cairn 0.1.0 — Public Beta v1

## What is included

- Cairn's launcher, onboarding and Home experience.
- An intentional pause for one selected app on the Free plan.
- Future Notes and River Report.
- A transparent plans screen showing Free, Monthly, Yearly and Lifetime options while purchasing remains unavailable.
- A fully offline Public Beta build with no analytics, crash telemetry or automatic update checking.

## Plans shown in this beta

- Free — One app
- Monthly — $7.99 / month
- Yearly — $69 / year
- Lifetime — $149 once

There is no checkout, waitlist, Trial or entitlement simulation in Public Beta v1.

## Important boundary

Cairn's intentional pause is part of the Cairn launcher experience. Recent apps, notifications, other launchers and other system launch paths can bypass it; this beta is not a system-wide blocker.

## Updates

Cairn does not check for updates in the app. Check the canonical Cairn Releases surface manually and verify the APK metadata before installing a newer version.
