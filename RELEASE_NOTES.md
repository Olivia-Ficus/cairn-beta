# Historical Release Notes — Cairn 0.1.0 Public Beta v1

These notes describe the historical GitHub release `v0.1.0-public-beta.1`. They do not describe the current Google Play Beta build or provide current installation instructions.

Cairn installation packages are no longer distributed through GitHub. To participate in the current Beta Test, use the [Google Play testing page](https://play.google.com/apps/testing/com.cairn.launcher).

## What was included

- Cairn's launcher, onboarding and Home experience.
- An intentional pause for one selected app on the Free plan.
- Future Notes and River Report.
- A transparent plans screen showing Free, Monthly, Yearly and Lifetime options while purchasing remained unavailable.
- A fully offline Public Beta build with no analytics, crash telemetry or automatic update checking.

## Plans shown in that build

- Free — One app
- Monthly — $7.99 / month
- Yearly — $69 / year
- Lifetime — $149 once

There was no checkout, waitlist, Trial or entitlement simulation in Public Beta v1.

## Important boundary

Cairn's intentional pause was part of the Cairn launcher experience. Recent apps, notifications, other launchers and other system launch paths could bypass it; the beta was not a system-wide blocker.

## Current Beta Test

GitHub is no longer an installation or update channel for Cairn. Join the current Beta Test through [Google Play](https://play.google.com/apps/testing/com.cairn.launcher).
